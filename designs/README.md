# Git Sync Service 设计文件

本目录包含 Git Sync Service 的 UI 设计文件。

## 文件结构

```
designs/
├── index.html          # 同步任务列表页面
├── history.html        # 同步历史页面
├── create-task.html    # 创建同步任务页面
├── styles.css          # 共享样式表
└── README.md           # 本文件
```

## 页面说明

### 1. 同步任务列表页面 (index.html)

主要功能：
- 显示所有同步任务的列表
- 统计卡片显示任务总数、运行中、今日同步、失败任务
- 支持搜索和筛选
- 每个任务显示源分支、目标分支、同步模式、状态
- 支持编辑、运行、删除操作
- 显示最近同步历史时间线

### 2. 同步历史页面 (history.html)

主要功能：
- 显示所有同步执行的历史记录
- 统计概览：总执行次数、成功次数、失败次数、平均耗时
- 支持按状态、任务、日期范围筛选
- 每条记录显示：
  - 分支流向（源分支 → 目标分支）
  - 同步详情（提交数量、开始/结束时间、状态）
  - 同步的提交列表
  - 可展开的详细日志

### 3. 创建同步任务页面 (create-task.html)

主要功能：
- 分步表单引导用户创建任务
- 步骤：基本信息 → 同步配置 → 高级设置 → 确认创建
- 配置项：
  - 任务名称和描述
  - 源仓库和目标仓库
  - 源分支和目标分支
  - 同步模式（单分支/全分支）
  - 定时表达式（支持预设）
- 实时预览任务配置

## 设计规范

### 颜色系统

- 主色调：蓝色 (#3b82f6)
- 成功色：绿色 (#22c55e)
- 警告色：黄色 (#f59e0b)
- 错误色：红色 (#ef4444)
- 中性色：灰色系列

### 组件库

- 按钮：主要、次要、成功、危险、幽灵
- 输入框：文本、选择、复选框
- 卡片：基础卡片、统计卡片
- 表格：数据表格
- 标签：状态标签
- 模态框：创建/编辑模态框
- 时间线：历史记录时间线
- 分页：分页导航

### 响应式设计

- 桌面端：完整布局
- 平板端：调整表格和统计卡片
- 移动端：单列布局，侧边栏折叠

## 使用方式

1. 直接在浏览器中打开 HTML 文件查看设计
2. 所有页面共享 `styles.css` 样式表
3. 使用现代浏览器（Chrome、Firefox、Safari）获得最佳体验

## 设计决策

### 布局

- 使用侧边栏导航，固定在左侧
- 主内容区占据剩余空间
- 统计卡片使用网格布局
- 表格使用全宽布局

### 交互

- 按钮悬停有视觉反馈
- 表单输入框聚焦有高亮效果
- 模态框有淡入动画
- 日志区域可展开/收起

### 信息架构

- 任务列表作为主要入口
- 历史记录作为辅助页面
- 创建任务使用分步表单
- 重要操作有确认提示
