Webhook 同步触发 — 交互流程图

Git Push → Webhook → 规则匹配 → 分支过滤 → 执行同步

1
阶段一：事件发起
1
Git Push 触发
开发者推送到 GitHub / GitLab / Gitea
git push origin feature/new-ui
→
2
发送 Webhook
平台发送 HTTP POST 到回调地址
POST https://api.example.com/api/webhooks/receive
→
3
接收请求
Webhook Receiver 处理入站请求
POST /api/webhooks/receive
2
阶段二：事件处理
4
验证签名
HMAC-SHA256 校验 Webhook Secret
p.ValidateWebhookSignature(r, secret)
→
5
解析事件
提取分支、提交、作者等信息
p.ParseWebhookEvent(r, secret) → NormalizedEvent
→
6
匹配仓库
按 PlatformOwner/PlatformRepo 匹配
repo.FullName == event.Repo.FullName
→
7
持久化事件
保存 WebhookEvent 到数据库
db.Create(&WebhookEvent{...})
3
阶段三：规则匹配
8
查询规则
获取所有 enabled 的 WebhookRule
db.Where("enabled = ? AND provider_config_id = ?", true, cfgID).Find(&rules)
→
9
匹配事件类型
rule.EventTypePattern ↔ event.Type
matchPattern("push", "push") ✓
→
10
匹配仓库 + 分支
RepoPattern + BranchPattern 过滤
matchPattern("*/backend", "user/backend") ✓
matchPattern("feature/*", "feature/new-ui") ✓
→
11
防抖检查
检查 MinInterval 防止重复触发
time.Since(lastTrigger) > minInterval ✓
4
阶段四：同步执行
12
查找同步任务
解析 SyncTaskKeys 获取任务列表
taskKeys = strings.Split(rule.SyncTaskKeys, ",")
→
13
分支匹配
single: SourceBranch == EventBranch
all-branch: 始终匹配
task.SourceBranch == extractBranch(event)
或 task.SyncMode == "all-branch"
→
14
获取分布式锁
防止多实例重复执行
lockSvc.UpWait(ctx, lockKey, 5*time.Minute)
→
15
创建 SyncRun
记录同步运行状态
db.Create(&SyncRun{TriggerSource: "webhook"})
5
阶段五：完成
16
Git Fetch + Push
执行代码同步操作
git fetch origin → git push target sourceHash:targetBranch
→
17
保存执行日志
更新 SyncRun 状态和详情
run.Status = "success" / "failed"
run.Details = logs.String()
→
18
发送通知
Webhook/邮件通知同步结果
notificationSvc.NotifySvc.Send(msg)
→
完成

分支匹配示例

// 单分支同步 (sync_mode = "single")
规则: branch_pattern = "feature/*"
事件: push to feature/new-ui → ✅ 匹配，触发同步
事件: push to main → ❌ 不匹配，跳过

// 全分支同步 (sync_mode = "all-branch")  
规则: branch_pattern = "" (留空)
事件: push to feature/new-ui → ✅ 始终触发
事件: push to main → ✅ 始终触发

// 多分支匹配
规则: branch_pattern = "feature/*, release/*"
事件: push to feature/auth → ✅ 匹配
事件: push to release/v2.0 → ✅ 匹配
事件: push to hotfix/bug → ❌ 不匹配
