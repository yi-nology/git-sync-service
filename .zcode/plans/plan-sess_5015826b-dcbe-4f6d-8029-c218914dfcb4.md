# Git Sync Service — 全面修复计划

根据批判性审查结果，按优先级修复所有已识别的问题。共 7 个工作组，约 30 处修改，涉及 20 个文件。

---

## 工作组 1: CI/CD 流水线修复 (P0)

### 1.1 修复 release.yml Go 版本不一致
**文件**: `.github/workflows/release.yml`
- 第 22、45 行: `go-version: '1.23'` → `go-version: '1.26'`（与 ci.yml 和 go.mod 一致）

### 1.2 修复 release 构建缺少 CGO
**文件**: `.github/workflows/release.yml`
- 项目依赖 `mattn/go-sqlite3` 需要 CGO，release 构建必须启用 CGO
- 为 linux 平台安装交叉编译工具链（gcc-aarch64-linux-gnu 等）
- 为 darwin/windows 启用 CGO 交叉编译

### 1.3 更新 codecov action 版本
**文件**: `.github/workflows/ci.yml`
- `codecov/codecov-action@v3` → `codecov/codecov-action@v4`

## 工作组 2: 安全修复 (P0/P1)

### 2.1 API Key 常量时间比较 + 空 Key 拒绝
**文件**: `biz/router/git_sync/middleware.go`
- 使用 `crypto/subtle.ConstantTimeCompare` 防止时序攻击
- 空 API Key 时拒绝所有请求（当前是放行）

### 2.2 Webhook Secret 加密存储
**文件**: `internal/dao/repo_dao.go`
- Create/Update/FindByKey 中对 WebhookSecret 进行 AES-256-GCM 加解密

### 2.3 Dockerfile 安全加固
**文件**: `Dockerfile`
- 添加非 root 用户、固定 alpine 版本 `alpine:3.20`、添加 HEALTHCHECK

### 2.4 清理 Git 仓库中的构建产物
**文件**: `.gitignore`
- 添加 `coverage.out` 条目

## 工作组 3: 错误处理修复 (P0)

## 工作组 4: Goroutine 生命周期管理 (P0)

### 4.1 cleanup goroutine 停止机制
**文件**: `internal/service/service.go`, `internal/service/cleanup.go`
- 添加 `context.CancelFunc` 和 `sync.WaitGroup`
- `cleanupTriggerTimes` 接受 context，通过 `select` 监听取消信号
- `Stop()` 中调用 cancel 并等待所有 goroutine 完成

### 4.2 webhook goroutine context 传播
**文件**: `internal/service/webhook.go`
- `context.Background()` → 使用 service-level 可取消 context
- 通过 WaitGroup 跟踪 goroutine
