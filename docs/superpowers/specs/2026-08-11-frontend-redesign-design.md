## 1. 项目概述

### 1.1 项目背景

Git Sync Service 是一个 Git 仓库同步微服务，前端使用 Vue 3 + Ant Design Vue 构建。当前前端存在以下问题：

- **操作效率低**：常用功能需要多次点击才能完成
- **信息架构不清晰**：重要信息未突出显示
- **表单体验差**：缺少默认值、提示、验证
- **状态反馈不明确**：加载状态、操作反馈、错误提示不够清晰

### 1.2 设计目标

- **操作效率**：减少操作步骤，常用功能一键可达
- **信息架构**：信息层次清晰，重要信息突出显示
- **表单体验**：表单有默认值、提示、验证，减少用户输入
- **状态反馈**：加载状态、操作反馈、错误提示清晰明确

### 1.3 技术栈

- **前端**：Vue 3 + Composition API + Ant Design Vue 4.x + Pinia + TypeScript
- **后端**：Go + Hertz 框架 + GORM ORM

## 2. 设计规范

### 2.1 设计风格

采用现代 SaaS 风格，类似 Vercel、Netlify 的简洁现代设计。

**设计原则**：
- **简洁**：减少视觉噪音，突出核心内容
- **一致**：统一的间距、颜色、字体、交互模式
- **高效**：常用操作一键可达，减少操作步骤
- **清晰**：信息层次分明，状态反馈明确

### 2.2 色彩系统

```scss
// 主色调
$primary: #1677FF;        // 主色（蓝色）
$success: #52C41A;        // 成功（绿色）
$warning: #FAAD14;        // 警告（橙色）
$error: #FF4D4F;          // 错误（红色）

// 中性色
$text-primary: #1F1F1F;   // 主要文字
$text-secondary: #8C8C8C; // 次要文字
$text-tertiary: #BFBFBF;  // 辅助文字
$bg-primary: #FFFFFF;     // 主背景
$bg-secondary: #F5F5F5;   // 次背景
$border: #E8E8E8;         // 边框
```

### 2.3 间距系统

```scss
$spacing-xs: 4px;
$spacing-sm: 8px;
$spacing-md: 16px;
$spacing-lg: 24px;
$spacing-xl: 32px;
```

### 2.4 圆角系统

```scss
$radius-sm: 4px;
$radius-md: 8px;
$radius-lg: 12px;
$radius-xl: 16px;
```

### 2.5 组件规范

**按钮**：
- 主按钮：`type="primary"` 用于主要操作
- 次按钮：`type="default"` 用于次要操作
- 文字按钮：`type="link"` 用于表格内操作
- 危险按钮：`danger` 用于删除等危险操作

**表格**：
- 统一分页配置：`pageSize: 10, showSizeChanger: true`
- 空状态：显示引导性操作按钮
- 加载状态：骨架屏或加载动画

**表单**：
- 布局：`layout="vertical"`
- 必填标识：使用 `required` 属性
- 提示信息：使用 `form-tip` 样式
- 验证：实时验证 + 提交验证

**反馈**：
- 成功：`message.success()`
- 错误：`message.error()` 或 `notification.error()`
- 警告：`message.warning()`
- 加载：按钮 `loading` 属性 + 骨架屏

- 显示服务运行状态

- 当前版本号

## 11. 实施计划

**第一阶段：基础重构（1-2周）**
- 统一设计规范（颜色、间距、字体、组件）

- 重构仪表盘为工作台
- 重构同步任务列表和创建流程
- 重构仓库管理（卡片式布局、两步式添加）
- 后端API调整（分页、筛选、批量操作）

**第三阶段：功能增强（1-2周）**
- 重构触发配置（规则列表、事件日志）
- 新增系统状态API
- 平台仓库导入功能
- 性能优化和测试
